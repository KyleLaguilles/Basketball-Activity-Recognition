[1] THE RISK PROXY -- tiers, weights, and the assertion that guards them
================================================================================================================

  R_c(s) = sum_k w_{tier(k)} * f_{c,k}(s),  f = fraction of session s in class k
  under condition c. Fractions, not seconds: session length divides out.

  tier 3 (landing/explosive) : shot, rebound, layup
  tier 2 (locomotion/load  ) : dribbling, pass, running
  tier 1 (rest/low         ) : walking, standing, sitting

  vector             w3     w2     w1   ordering
  ----------------------------------------------
  A_linear            3      2      1   3 > 2 > 1 >= 0  OK
  B_moderate          5      2      1   5 > 2 > 1 >= 0  OK
  C_strong           10      3      1   10 > 3 > 1 >= 0  OK
  D_compressed        5      3      1   5 > 3 > 1 >= 0  OK
  E_zero_rest         3      2      0   3 > 2 > 0 >= 0  OK
  ----------------------------------------------

  All 5 vectors satisfy w3 > w2 > w1 >= 0 and TIER_MAP covers all
  9 classes exactly; both were asserted before any run was loaded.
